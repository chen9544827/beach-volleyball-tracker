# 與對方討論規格清單

> **目的：** 確認對方提供的影片規格 + 對方需要的輸出資料格式 + 進度與時程報告
> **討論對象：** 影片提供方 / 資料需求方

---

## 一、影片資料集規格（需要對方提供）

| # | 問題 | 為什麼需要問 |
|---|------|-------------|
| A1 | 2000 部影片的解析度分布？（全部 720p？還是混合？） | 影響系統是否需要支援多解析度 |
| A2 | 影片 FPS 是否統一？（25fps / 30fps / 其他？） | 影響時間相關的分析精度 |
| A3 | 實際有多少個不同場地？ | 影響需要建立多少組場地配置 |
| A4 | 每個場地有幾個攝影機角度？（C1-C4 都有嗎？） | 同上，影響配置數量 |
| A5 | 檔名格式是否 100% 遵循已知模板？是否有例外？ | 影響自動化解析的可靠度 |
| A6 | 是否有已知的「問題影片」？（如畫面異常、缺失片段） | 可提前排除，節省處理時間 |
| A7 | 影片是否已全部提供？還是會分批交付？ | 影響批次處理的排程 |

## 二、對方需要的輸出資料（需要對方確認）

| # | 問題 | 選項 |
|---|------|------|
| B1 | 輸出格式偏好？ | Excel (.xlsx) / CSV / JSON / 都可以 |
| B2 | 每一行代表什麼？ | 每次發球一行 / 每個片段一行 / 每部影片一行 |
| B3 | 需要哪些欄位？（請對方確認） | 見下方欄位清單 |
| B4 | 擊球速度/跳躍高度需要真實物理單位（km/h, cm）嗎？還是像素值即可？ | 物理單位需要額外的場地校準工作 |
| B5 | 是否需要「品質信心度」欄位？（表示該筆資料的可靠程度） | 幫助對方篩選不確定的結果 |
| B6 | 低信心度的結果要保留還是排除？ | 標記保留 / 直接排除 / 分開輸出 |
| B7 | 是否需要聚合統計表？（如按場地/年份/性別的彙總） | 額外工作量 |

### 目前可提供的欄位清單

**基本資訊：**
- 影片名稱、片段名稱
- 場地名、年份（WT18/WT19）、性別（M/W）、輪次（QT/MD/SF/F）
- 攝影機編號（C1-C4）

**發球分析：**
- 發球類型：跳發 (jump) / 站發 (standing)
- 發球員編號（影片中的位置識別，非姓名）
- 拋球幀號、擊球幀號
- 擊球速度（px/frame，可轉換為相對速度）
- 跳躍高度（px，可依解析度正規化）

**品質指標：**
- 分析信心度（0-1）
- 品質等級（A/B/C/F）
- 球偵測率
- 球員偵測率
