# 沙灘排球影片分析專案 (Beach Volleyball Tracker)

## 專案總覽

本專案旨在自動化分析沙灘排球比賽影片，透過物件偵測 (YOLO) 和電腦視覺演算法，實現以下核心目標：
1.  **自動偵測發球事件**：精準識別每一次發球的瞬間。
2.  **鎖定發球員**：準確判斷是由哪一位球員執行發球。
3.  **分析發球位置**：將發球員的位置對應到球場上的 A, B, C 三個戰術區域。

此工具為教練、球員及數據分析師提供了一套強大的量化分析方法，能夠從大量的影片中快速提取關鍵的戰術數據。

---

## 主要功能

* **高準確度的發球判斷**：採用基於狀態機的複雜演算法，詳細分析球的運動軌跡（拋球、頂點、擊球），能有效過濾非發球的高速擊球事件。
* **精準的發球員識別**：
    * **回溯尋人法**：在偵測到擊球後，自動往前倒帶數幀，在球員與球最接近的「黃金時刻」進行判斷。
    * **點對框最短距離演算法**：徹底解決因攝影機透視造成的判斷錯誤，使用更符合人類直覺的「點到矩形邊緣」最短距離來計算球與球員的遠近。
* **戰術區域分析**：能夠根據預先定義的球場邊界，自動將發球員的位置標示為 A, B, C 三個區域之一，提供戰術分析依據。
* **高度可配置性**：幾乎所有的演算法參數（如速度閾值、時間窗口、距離參數等）都可以透過命令列進行微調，方便針對不同影片來源進行優化。
* **視覺化的分析結果**：自動產生標記了發球員、擊球點和發球區域的圖片，方便使用者直觀地驗證和分析結果。
* **批次處理能力**：支援一次處理資料夾中的多個影片檔案，並利用多核心平行處理以提升效率。

## 安裝與需求

1.  **Python 環境**: 建議使用 Python 3.8 或更高版本。
2.  **相依套件**: 專案會自動嘗試安裝 `tqdm`，但建議您先手動安裝好所有必要的套件：
    ```bash
    pip install opencv-python numpy tqdm
    ```
3.  **模型檔案**: 請確保您的物件偵測模型 (YOLOv8) 相關檔案已放置在正確的目錄下，供 `track_ball_and_player.py` 腳本使用。

## 使用教學

本專案的使用流程分為兩個主要步驟：

### **第一步：定義球場邊界 (只需對同類視角做一次)**

為了讓程式能夠進行發球區域分析，您必須先提供一個定義了球場四個角落座標的設定檔。

1.  **執行設定檔產生器**:
    ```bash
    python court_definition/court_config_generator.py --video_path "path/to/your/sample_video.mp4"
    ```
2.  **標示球場角落**:
    * 程式會顯示影片的第一幀畫面。
    * 請**務必依照 `左上 -> 左下 -> 右下 -> 右上` 的順序**，用滑鼠左鍵點擊球場的四個角落。這個順序對後續的區域判斷至關重要。
    * 點擊四個點後，按鍵盤上的 `q` 鍵退出。
3.  **產生設定檔**:
    * 腳本會在 `court_definition` 資料夾下產生一個名為 `court_config.json` 的檔案。這個檔案將被用於所有相同視角的影片分析。

### **第二步：執行主分析程式**

這是分析所有影片並產生結果的核心步驟。

1.  **基本執行指令**:
    ```bash
    python run_analysis_all_in_one.py --input_folder "包含所有影片的資料夾" --court_config "court_definition/court_config.json"
    ```

2.  **常用參數調整範例**:
    * 若覺得發球員判斷的時間點不對，可以調整 `--search_offset` 參數：
        ```bash
        python run_analysis_all_in_one.py --input_folder "影片資料夾" --court_config "court_config.json" --search_offset 5
        ```
    * 若想調整發球偵測的速度門檻，可以使用 `--hit_v`：
        ```bash
        python run_analysis_all_in_one.py --input_folder "影片資料夾" --court_config "court_config.json" --hit_v 45
        ```

## 命令列參數詳解

主程式 `run_analysis_all_in_one.py` 提供豐富的參數來自訂分析流程。

| 參數名稱 | 必要性 | 預設值 | 說明 |
| :--- | :---: | :---: | :--- |
| `--input_folder` | **必要** | - | 包含待分析影片的資料夾路徑。 |
| `--court_config` | **必要** | - | 由第一步產生的 `court_config.json` 檔案路徑。 |
| `--output_folder`| 可選 | `volleyball_analysis_results` | 儲存所有分析結果的根目錄。 |
| `--workers` | 可選 | 電腦核心數 | 用於平行處理的CPU核心數量。 |
| `--overwrite` | 可選 | `False` | 加上此旗標會強制重新分析所有影片，覆蓋舊結果。 |
| `--search_offset`| 可選 | `3` | **(重要)** 從偵測到擊球的幀往前「回溯」幾幀來尋找發球員。 |
| `--hit_v` | 可選 | `40.0` | 偵測擊球的最小瞬時速度。 |
| `--toss_vy` | 可選 | `8.0` | 觸發「疑似拋球」的最小初始垂直向上速度。 |
| `--vertical_ratio`| 可選 | `1.5` | 拋球時，垂直速度必須是水平速度的最小倍數。 |
| *(... 其他偵測參數)* | 可選 | (各自不同) | 您的發球偵測演算法所使用的其他微調參數。 |

## 輸出結果說明

分析完成後，所有的結果會儲存在您指定的 `--output_folder` 中。

* **`first_hit_summary_with_zone/`**: 此資料夾包含了最終的分析結果。
    * **`..._zoned.jpg`**: 標示了發球員、發球區域 (Zone A/B/C) 的最終結果圖。
    * **`..._SEARCH_DEBUG.jpg`**: 用於偵錯的關鍵幀圖片，上面標示了所有被偵測到的球員，以及程式計算出的「球到球員的精確距離」，方便您驗證演算法的判斷依據。
    * **`first_hit_frames...txt`**: 文字格式的總結報告，記錄了每個影片的擊球幀和發球區域。
* **`影片名稱/`**: 每個影片都會有一個對應的子資料夾。
    * **`tracking_output/`**: 儲存了物件追蹤的原始數據 (`..._all_frames_data_with_pose.json`)。
    * **`analysis_output/`**: 儲存了分析後的影片。
    * **`processing.log`**: 該影片的詳細處理日誌。
* **`summary_report.txt`**: 記錄了整個批次處理任務的成功、失敗與跳過列表的總報告。

## 疑難排解 (Troubleshooting)

* **發球員判斷錯誤**：
    1.  首先檢查 `..._SEARCH_DEBUG.jpg` 偵錯圖片。
    2.  查看圖片上標示的距離 (`D:xx.x`)，確認程式計算出的最近球員是否符合預期。
    3.  如果不符合，嘗試調整 `--search_offset` 參數（例如從 `3` 調整為 `5` 或 `2`），找到一個球與發球員距離最近的黃金時間點。
* **發球區域 (A/B/C) 判斷錯誤**:
    1.  確認您在執行 `court_config_generator.py` 時，點擊四個角落的**順序**是否正確 (`左上 -> 左下 -> 右下 -> 右上`)。
    2.  檢查 `..._zoned.jpg` 圖片上繪製的球場邊界和分區線是否準確。
* **發球事件偵測不準確**:
    * 這代表您演算法的核心參數需要微調。請根據影片特性，調整 `--hit_v`, `--toss_vy`, `--vertical_ratio` 等參數。
